# Qt-OpenStreetMap

Here I have uploaded code I directly used for files and presentations related to digital maps, both 
frond-end components to display base Open Street Maps with GIS attribute layers/data sets, and 
tools for creating custom tile styles and servers if desired.  This code was geared toward those 
specific projects and has not been edited or commented with documentation suitable for a 
library intended for public use.

I plan to improve the documentation and layout of this code in the future, but other 
modules are more of a prioty for me right now.
